# 公開方針と情報保護

## 公開するもの

- プロジェクトの目的と設計思想
- 外部データに依存しない代表分析ロジック
- 空のSQLiteスキーマ
- 架空データを使うデモ
- 単体テスト
- ロードマップ

## 公開しないもの

- `.db`、`.sqlite`、CSV、Parquetなどの収集済みデータ
- 保存したHTML、画像、スクリーンショット
- Cookie、セッショントークン、APIキー、パスワード
- ブラウザプロファイル、ログイン済みセッション
- 実名、個人メール、学校メール、学籍番号、住所、電話番号
- 端末内のユーザー名を含む絶対パス
- Private版のGit履歴
- 外部サイト固有の取得URLやセレクタの全量

## なぜ別リポジトリにするか

元のPrivateリポジトリをそのままPublicへ変更すると、現在のファイルだけでなく、過去コミットに削除済みの秘密情報が残っている可能性があります。そのため、公開用の新規リポジトリへ、安全性を確認したファイルだけを追加します。

## 公開前の確認

```bash
python scripts/check_public_safety.py
python -m unittest discover -s tests -v
```

加えて、Gitへ追加した後に次を目視します。

```bash
git status
git diff --cached --stat
git diff --cached
```

初回コミット前に、Gitの公開名と公開メール設定も確認します。

```bash
git config --local user.name
git config --local user.email
```

## データに関する考え方

本リポジトリは収集プログラムの運用成果ではなく、設計・実装能力を示すポートフォリオです。第三者が提供するデータ自体は配布せず、外部データの権利と利用条件を尊重します。
